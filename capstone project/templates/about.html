Project Objective

This project builds an automated machine learning system that analyzes text-based customer feedback (product reviews) and classifies each review into one of three sentiment categories: Positive, Neutral, or Negative.

By classifying opinion mining data, businesses can monitor brand reputation, spot negative feedback in real time to resolve service complaints, and extract actionable consumer insights to guide future product design.

NLP Preprocessing Pipeline

Before raw reviews can be evaluated by the Machine Learning model, they must undergo extensive Natural Language Processing (NLP) to clean noise and standardize syntax. The pipeline consists of the following steps:

1. Lowercase Standard

Normalizes case representation (e.g. "Amazing" vs "amazing") to prevent the model from treating capitalized terms as unique features.

2. Punctuation Strip

Removes tags, commas, exclamation marks, and numeric symbols. Focuses classification strictly on alphabetical sentiment indicators.

3. Tokenization

Splits the continuous text strings into individual linguistic tokens (words) to analyze term frequency distributions.

4. Stopword Removal

Excludes highly frequent words that lack unique sentiment signal (e.g., "the", "is", "at", "for") using NLTK's English stopword corpus.

Algorithms & Mathematical Models

TF-IDF Vectorization

TF-IDF (Term Frequency-Inverse Document Frequency) measures how important a word is to a document relative to a corpus. It weights common terms down and increases weights of unique sentiment words (like "terrible" or "perfect"), translating strings into high-dimensional mathematical vectors.

Naive Bayes Classification

Naive Bayes is a probabilistic classifier based on **Bayes' Theorem**. It is called "naive" because it assumes that the occurrence of a particular feature (word) is independent of the occurrence of other features.

P(C | X) = [ P(X | C) × P(C) ] / P(X)
Where:
  • P(C | X): Posterior probability of Class C (Positive/Neutral/Negative) given Feature Vector X.
  • P(X | C): Likelihood of observing features X given that the document belongs to Class C.
  • P(C): Prior probability of Class C in the dataset.
  • P(X): Prior probability of observing Feature Vector X.
